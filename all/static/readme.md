# Система управления задачами

Учебный проект по производственной практике. Веб-приложение для управления задачами небольшой команды.

## Возможности
- Создание, редактирование и удаление задач
- Проекты: задача привязывается к проекту из списка
- Исполнители: назначение сотрудника на задачу (с контактами: Telegram, телефон)
- Приоритет задачи: низкий, средний, высокий
- Статусы: «Новая», «В работе», «Выполнена»
- Срок выполнения задачи
- Поиск задач по названию
- Фильтрация по статусу
- Сортировка по сроку выполнения и по приоритету
- Блок статистики: всего задач, готово, в работе, не готово
- Всплывающие уведомления о действиях
- Смена темы (светлая/темная) и обоев
- Скрытие выполненных задач
- Выбор вида отображения (сетка или список)
- Сохранение данных в базе данных SQLite (серверная часть)
- Адаптивный дизайн для компьютеров и телефонов

## Технологии
- Python (Flask)
- SQLite (база данных)
- HTML5
- CSS3
- JavaScript (fetch API для связи с сервером)

## Структура проекта
- `app.py` — серверная часть на Flask (маршруты, работа с базой данных)
- `database.db` — файл базы данных SQLite (создается автоматически)
- `templates/index.html` — главная страница
- `static/style.css` — оформление
- `static/script.js` — логика работы с задачами и интерфейсом
- `static/images/` — фоновые картинки и обои
- `requirements.txt` — зависимости для запуска
- `Procfile` — конфигурация для хостинга Render
